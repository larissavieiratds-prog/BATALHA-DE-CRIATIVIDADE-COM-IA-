# BATALHA-DE-CRIATIVIDADE-COM-IA-
É um jogo de Combate, que você batalha contra a IA, tem quatro personagens, dois masculinos e dois femininos os nomes deles são:Raven,Kael,Ayra e Naomi
Este jogo contem três níveis de dificuldade o fácil, o médio, e o difícil, você também escolhe sua arena de jogo o nome das arenas de jogos disponíveis são: Cidade Neon, Vulcão, Templo de Gelo , Floresta Mística, e Arena espacial, na hora de jogar os botões são A,W e D suas funções são: o A anda para trás, o W anda para cima e pula, é a letra D vai para frente, cada personagem tem sua habilidade que fica embaixo do nome dele na hora de ser escolhido, o poder e usado na hora do combate
os botões para usar os poderes especiais ficam no canto direito do computador, tem soco, chute ,poder e o especial além de você pular e andar também tem que ter coordenação motora, para ativar o especial ou o poder. Basicamente esse e o jogo a maioria das coisas usamos a IA para fazer, usamos as linguagens: HTML responsável pela estrutura da tela, botões e estruturas do jogo, CSS utilizado para estilização, cores, menu, barra de vida, energia e organização e visual da interface ,Java Script Responsável pelas regras do jogo, movimentação do personagens, ataques ,poderes, inteligência artificial  e funcionamento dos controles e por fim , Three.js utilizado para construção e renderização cenários tridimensionais, iluminação, câmera e elementos gráficos 3D, espero que gostem de jogo.
