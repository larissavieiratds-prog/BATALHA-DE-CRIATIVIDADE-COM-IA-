📌 Sobre o Projeto

**Batalha de Criatividade com IA** é um jogo desenvolvido como projeto tecnológico e educacional. Nele, o jogador enfrenta um adversário controlado pela inteligência artificial, utilizando movimentação, ataques e habilidades especiais.

O jogo apresenta personagens com características próprias, diferentes níveis de dificuldade e cenários tridimensionais.

O objetivo é proporcionar uma experiência interativa, divertida e desafiadora, explorando a criatividade e a tecnologia no desenvolvimento de jogos digitais.

 🎮 Personagens

O jogo possui quatro personagens disponíveis:

| Personagem | Categoria |
| Raven | Masculino |
| Kael | Masculino |
| Ayra | Feminino |
| Naomi | Feminino |

Cada personagem possui sua própria habilidade especial, que pode ser utilizada durante o combate.

 🏟️ Arenas Disponíveis

O jogador pode escolher entre cinco cenários:

- 🌆 Cidade Neon
- 🌋 Vulcão
- ❄️ Templo de Gelo
- 🌳 Floresta Mística
- 🚀 Arena Espacial

 🏆 Níveis de Dificuldade

O jogo oferece três níveis:

- **Fácil:** desafio inicial.
- **Médio:** adversário com maior nível de desafio.
- **Difícil:** combate mais desafiador.

🕹️ Como Jogar

O jogador precisa utilizar os controles para movimentar seu personagem e realizar ações durante o combate.

| Tecla | Função |
| A | Movimentar para trás |
| W | Pular |
| D | Movimentar para frente |

Além da movimentação, existem botões de combate:

- **Soco:** ataque básico.
- **Chute:** outro tipo de ataque.
- **Poder:** habilidade do personagem.
- **Especial:** ataque especial.

É necessário coordenar os movimentos e escolher o momento adequado para utilizar as habilidades.

 ✨ Funcionalidades

- Escolha entre quatro personagens.
- Seleção de cinco arenas.
- Três níveis de dificuldade.
- Combate contra inteligência artificial.
- Movimentação dos personagens.
- Ataques e habilidades especiais.
- Interface interativa.
- Cenários tridimensionais.
- Barras de vida e energia.

 💻 Tecnologias Utilizadas

| Tecnologia | Aplicação |
| HTML5 | Estrutura das telas, menus e botões. |
| CSS3 | Estilização, cores, animações e interface. |
| JavaScript | Regras do jogo, movimentação, ataques e inteligência artificial. |
| Three.js | Construção e renderização dos cenários tridimensionais. |

🖥️ Como Executar o Projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Execute o projeto utilizando a extensão Live Server.
5. Abra o jogo no navegador.

 🎯 Objetivo do Projeto

O projeto busca demonstrar como a tecnologia e a inteligência artificial podem ser utilizadas no desenvolvimento de jogos digitais, estimulando a criatividade, o raciocínio lógico, a programação e o trabalho em equipe.

🚀 Considerações Finais

O desenvolvimento do Batalha de Criatividade com IA proporcionou uma experiência prática de criação de jogos, integração de tecnologias e resolução de problemas.

Mais do que um jogo, o projeto representa a união entre criatividade, programação e inovação tecnológica.
